- Source: https://www.solarsystemscope.com/textures/
- Download: https://www.solarsystemscope.com/textures/download/8k_saturn_ring_alpha.png
- License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
- Used as a radial color/opacity map, embedded in `public/models/saturn.glb`; appearance changes with material, UV placement, lighting and tone mapping.

Planet cloud map: generated by `create_saturn.py`, an artistic approximation. It is not a NASA image, a spacecraft observation, or a dated reconstruction of Saturn's weather.

The scene is an educational visualization, not a scientifically calibrated observation.

## Earth

Earth day, night and cloud maps by **Solar System Scope / INOVE**, CC BY 4.0, same source and license above. Original filenames: `8k_earth_daymap.jpg`, `8k_earth_nightmap.jpg`, `8k_earth_clouds.jpg`.

The original JPG download server returned 403 during this build, so these maps were retrieved from the public asset mirror at https://github.com/ZGdadong/Three.js-3D-Earth/tree/main/images (textures only; no application code copied). The mirrored cloud file size matches the upstream asset. They are resized to 4096 × 2048 for the embedded GLB and combined with custom lighting, day/night masking and a separate cloud sphere. Credit remains with the original texture author. Source inputs live in `art/textures/earth/`.

Clouds and city lights are illustrative composite maps, not live weather, power usage or a real-time solar terminator.

## Jupiter

Cloud map by Solar System Scope / INOVE, CC BY 4.0 (source and license above). Retrieved from https://github.com/Shriisoot/Planets-texture/blob/main/8k_jupiter.jpg (texture only). Despite its filename, this mirror is 4096 × 2048; the site accurately labels it 4K. Embedded unchanged in the GLB; appearance is modified by oblate geometry, orientation, material and lighting. This composite is not live weather. Planet facts: https://science.nasa.gov/jupiter/jupiter-facts/

## Mars

8192 × 4096 surface map by Solar System Scope / INOVE, CC BY 4.0 (source and license above), retrieved from https://raw.githubusercontent.com/fury-gl/fury-data/master/textures/8k_mars.jpg. SHA-256: 4cc52149924abc6ae507d63032f994e1d42a55cb82c09e002d1a567ff66c23ee, matching the FURY fetcher manifest. Texture embedded in GLB; orientation, roughness, shape, lighting and atmospheric rim adjusted for presentation. No elevation data or live weather is represented. Facts: https://science.nasa.gov/mars/facts/

## Venus

Embedded unchanged; orientation, material, light and atmospheric limb adjusted. Cloud patterns are illustrative/enhanced, not live weather or a calibrated true-color view. Facts: https://science.nasa.gov/venus/venus-facts/
