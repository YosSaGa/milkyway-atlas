# 🌌 Milky Way Atlas

เว็บสำรวจทางช้างเผือกและดาวเคราะห์ทั้ง 8 ดวงแบบ 3D สร้างด้วย **React, TypeScript, Three.js และ Blender**

## 🚀 [กดลองใช้เว็บไซต์](https://milkyway-atlas-yossa.spiffybull130.chatgpt.site/)

> เดโมปัจจุบันจำกัดสิทธิ์เข้าชม ต้องลงชื่อเข้าใช้ด้วยบัญชีที่ได้รับอนุญาต

- หมุนและซูมชมดาว พร้อมปรับแสง
- กล้องบินโค้งเข้าหาดาวพร้อมเอฟเฟกต์อวกาศ
- กดดาวข้างเคียงเพื่อเดินทางต่อ และเปิดดูรายละเอียด
- มีหน้าโหลดโมเดลและรองรับมือถือ

### รันบนเครื่อง

```bash
npm install
npm run dev
```

สร้างไฟล์สำหรับเผยแพร่ด้วย `npm run build`

โมเดลและสคริปต์ Blender อยู่ใน `art/` ดูเครดิตพื้นผิวที่ [ATTRIBUTION.md](art/ATTRIBUTION.md) ขนาด ระยะห่าง และการเคลื่อนที่ปรับเพื่อการนำเสนอ ไม่ใช่มาตราส่วนจริง
